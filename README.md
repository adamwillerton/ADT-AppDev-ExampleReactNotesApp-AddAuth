# Example Notes web app (No installs, Hosting‑only) 

This project uses React + Vibe.

It is a simple notes app with CRUD operations.  All data is stored in the browser (localStorage), there is no back-end.

## How to run this project (no installs)
1. On GitHub use the 'Use this Template' facility (green button in top-right). This will allow you to take a copy of this repo to your own GitHub account (giving it a suitable name etc).
2. In Render, connect your GitHub repo → Deploy a static site
   
   o  Branch: `main`
   
   o	Root Directory: `notes-app`
   
   o	Build Command: `npm install && npm run build`
   
   o	Publish Directory: `dist`
